═════════════════════════════════════════════════════════════════════════════════
  7-STEP AGENT CYCLE (Explain during demo)
═════════════════════════════════════════════════════════════════════════════════

Step 1: DATA EXPLORATION
  → Scan dataset, count audio files & species
  → Compute statistics for LLM context

Step 2: ARCHITECTURE PROPOSAL
  → Send context to LLM
  → LLM suggests model improvements (15-20 sec)

Step 3: CODE GENERATION
  → Extract Python code from LLM response
  → Validate against known API constraints
  → Use fallback if generation fails

Step 4: SANDBOXED EXECUTION
  → Run generated code in subprocess
  → Timeout protection (60-90 min per iteration)
  → Real-time metric reporting

Step 5: RESULTS CAPTURE
  → Parse stdout for metrics
  → Load metrics.json checkpoint
  → Save best model weights

Step 6: LLM-DRIVEN ANALYSIS
  → Send results back to LLM
  → LLM analyzes performance
  → Suggests next improvements

Step 7: ITERATION DECISION
  → Update state with new results
  → Save metrics to history
  → Loop continues (or stop)

DURING DEMO:
"Notice the validation AUC improving from 58% to 94% in minutes. This is the 
autonomous loop in action. Each iteration the agent learns from previous results 
and suggests strategic improvements."

ABOUT FOCAL LOSS:
"With 206 bird species and imbalanced data, some appear in only 2-3 recordings. 
Focal Loss focuses training on hard examples, ensuring all species get learned 
equally well."

ABOUT SPECAUGMENT:
"SpecAugment randomly masks frequency and time bands. This teaches the model to 
recognize birds even with incomplete audio—crucial for real-world robustness."

ABOUT MIXUP:
"Mixup blends pairs of training examples. This creates intermediate samples that 
smooth decision boundaries and reduce overfitting."

RESULTS HIGHLIGHT:
"After 202 iterations, we achieved 96.08% AUC. The agent discovered EfficientNet-B1 
as optimal. Nobody told it to try this—the agent figured it out through intelligent 
exploration."
