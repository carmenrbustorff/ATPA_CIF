##### 3. Implement Mixup Augmentation
Mixup is a powerful data augmentation technique that can improve generalization by creating new training samples through convex combinations of existing ones.

**Code Snippet:**
```python
# Mixup implementation
def mixup_data(x, y, alpha=0.4):
    if alpha > 0:
        lam = np.random.beta(alpha, alpha)
    else:
        lam = 1

    batch_size = x.size(0)
    index = torch.randperm(batch_size).to(device)

    mixed_x = lam * x + (1 - lam) * x[index, :]
    y_a, y_b = y, y[index]

    return mixed_x, y_a, y_b, lam

def mixup_criterion(criterion, pred, y_a, y_b, lam):
    return lam * criterion(pred, y_a.float()) + (1 - lam) * criterion(pred, y_b.float())
```

**Usage in Training Loop:**
```python
# Inside the training loop
inputs, targets = inputs.to(device), targets.to(device)
mixed_inputs, targets_a, targets_b, lam = mixup_data(inputs, targets)

with torch.autocast(device_type="cuda"):
    outputs = model(mixed_inputs)
    loss = mixup_criterion(focal_loss, outputs, targets_a, targets_b, lam)
```
