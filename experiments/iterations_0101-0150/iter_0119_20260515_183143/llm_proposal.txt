        x = self.pool(x).view(x.size(0), -1)
        return torch.sigmoid(self.classifier(x))

### Explanation:

1. **Model Architecture**:
   - The model has 3 convolutional layers followed by batch normalization and ReLU activation.
   - An adaptive average pooling layer is used to flatten the features.
   - A fully connected layer with dropout for regularization and another linear layer for classification.

2. **Training Loop**:
   - Data augmentation (frequency masking and time masking) is applied during training.
   - The model trains for 20 epochs, and early stopping is implemented if validation AUC does not improve for 5 consecutive epochs.

3. **Validation & Metrics**:
   - After each epoch, the model evaluates on the validation set to compute the AUC.
   - Metrics including final training loss, best validation AUC, number of parameters, epochs trained, batch size, and sample sizes are saved in a JSON file and printed.

This setup ensures rapid experimentation with systematic hyperparameter tuning, allowing for efficient exploration of different architectures and configurations.
