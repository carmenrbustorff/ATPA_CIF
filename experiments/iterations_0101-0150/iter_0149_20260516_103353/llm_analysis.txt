To ensure that all files are correctly accessed and loaded, you can implement a more robust file handling mechanism. This includes checking if each file exists before attempting to open it. Here is an example of how you might modify your data loader to handle missing or corrupted files:

```python
import os

def get_image_paths(data_dir):
    image_paths = []
    for root, _, files in os.walk(data_dir):
        for file in files:
            if file.endswith(('.png', '.jpg', '.jpeg')):
                full_path = os.path.join(root, file)
                if os.path.exists(full_path):  # Check if the file exists
                    image_paths.append(full_path)
    return image_paths
```
